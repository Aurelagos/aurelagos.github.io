# AI Project Portfolio

A static portfolio site (plain HTML and CSS, no build step).

## Publish on GitHub Pages

1. Create a new public repository, e.g. `taylorcollins.github.io` (a repo named `<username>.github.io` is served at that address), or any name if you prefer a project site.
2. Add `index.html`, `style.css`, and this README to the repo root and push.
3. In the repo, go to **Settings > Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Your site will be live within a minute or two.

## Adding a project

Copy one `<article class="card">` block in `index.html` and edit the title, tags, and bullets.

## Before you publish

- Add your contact links in the Contact section.
- Re-read each project for anything you would not want public (employer details, account info, names of private sources).
